# Практическая работа 01

Нужно реализовать на C++ две задачи в MongoDB:

1. Показать страницы каталога товаров из `shop.products`:
   фильтр по категории, сортировка, `skip`, `limit`, проекция и общее количество.
2. Обработать поставку в `sandbox.products`:
   использовать `$inc` для остатков, добавить две новые позиции, удалить
   `SKU-CP-018` и установить `free_shipping: true` всем аксессуарам.

Базу `shop` изменять нельзя. Проверка должна показать `12 из 12`.
